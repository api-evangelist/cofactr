# Cofactr

> Cofactr provides electronics supply chain infrastructure — component intelligence, procurement execution, and ITAR-registered warehousing and kitting — so hardware teams avoid shortages and production delays. It exposes two REST APIs: the Knowledge Graph (Component Cloud) API for component data, and the Platform API for BOMs, POs, kits, and inventory.

## APIs

- [Cofactr Knowledge Graph (Component Cloud) API](https://graph.cofactr.com): Component intelligence — search parts, view products, offers, pricing, and specs. OpenAPI 3.1 at https://graph.cofactr.com/openapi.json. Auth: X-CLIENT-ID + X-API-KEY headers.
- [Cofactr Platform API](https://flagship-api.cofactr.com/): BOMs, purchase orders, kits, invoices, and inventory. Auth: `Authorization: Api-Key <key>`. Docs: https://developers.cofactr.com/
